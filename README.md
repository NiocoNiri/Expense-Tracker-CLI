# 💰 Expense Tracker CLI

Консольное приложение для учёта личных расходов с использованием SQLite.

## 📋 Описание

Expense Tracker CLI - это простое консольное приложение, которое позволяет:
- Добавлять расходы с указанием даты, категории и суммы
- Просматривать все добавленные расходы
- Автоматически сохранять данные в базу данных SQLite

## 🚀 Возможности

- ✅ Добавление расходов (дата, категория, сумма)
- ✅ Просмотр всех расходов с итоговой суммой
- ✅ Автоматическое сохранение в SQLite базу данных
- ✅ Защита от SQL-инъекций через параметризованные запросы
- ✅ Автоинкрементируемый ID для каждой записи

## 📦 Требования

- Python 3.7 или выше
- Библиотека `sqlite3` (входит в стандартную поставку Python)
